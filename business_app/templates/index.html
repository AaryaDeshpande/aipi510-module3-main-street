How the model is checked

Loading the training and evaluation record…

Mean absolute error (MAE) measures the average prediction error in business locations. The no-change baseline predicts the same count as the input year. Model selection uses validation data; held-out test results provide a separate final check.

Cleaning, cloud ingestion, configuration, training, MLflow tracking, saved artifacts, Docker, and the prediction service are documented with the project source.
